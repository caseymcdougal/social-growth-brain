# Social Audit Dashboard

**register:** product

## Users

Casey McDougal — solo X/Twitter creator improving content through private, local-first analysis. Technical enough to run local tools; wants clarity over configuration.

## Product purpose

A private creator strategy room on the Mac. Scan public X posts, learn what is working and why, and write the next post — without SaaS analytics noise or ops-dashboard jargon.

## Tone

- Coach-led, encouraging, plain language
- One obvious next action per visit
- Celebrate insight before asking for more work
- Trust through transparency (local, read-only, no auto-posting)

## Anti-patterns

- Generic SaaS analytics grids and metric walls
- Ops vocabulary: "production queue", "workflow tracker", "source evidence"
- Multiple competing primary CTAs on one screen
- Burying the coach lesson or ranked posts behind collapsed panels

## Strategic principles

1. **Story order:** See posts → Find what worked → Understand why → Write next post
2. **Phase gating:** Show only what the current step needs; advanced tools stay optional
3. **Emotional payoff:** Audit completion should feel like a win before draft generation
4. **Mobile parity:** Bottom dock must preserve step meaning, not just labels
